# Proyecto CLI para el manejo de pedidos

Aplicación de consola para administrar proveedores, productos y órdenes. Permite registrar, buscar, listar, procesar, cancelar y eliminar registros, además de validar datos como prioridad, estado y precios. La lógica está implementada en tres versiones equivalentes: C#, Dart y Java.

## Cómo ejecutarlo

### C#
```bash
cd proyecto_c#
dotnet run
```

### Dart
```bash
cd proyecto_dart
dart pub get
dart run
```

### Java
```bash
cd proyecto_java
mvn clean compile
mvn exec:java -Dexec.mainClass=com.company.Main
```

Cada versión abre un menú interactivo en consola para gestionar el sistema de pedidos.
